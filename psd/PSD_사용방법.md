# both 이미지와 대응하는 편집용 PSD

## 파일 대응

`base.psd` → `base.png`이며 나머지도 같은 이름입니다.
PSD 캔버스 크기, 파츠 위치, 이미지 칸 간격, 기본/눌림 배열은 both/local의 PNG와 맞췄습니다.

| PSD | 크기(px) | 왼쪽에서 오른쪽으로 |
|---|---|---|
| triggers.psd | 460 × 434 | L2 · R2 |
| bumpers.psd | 458 × 144 | L1 · R1 |
| touchpad.psd | 724 × 704 | 단일 이미지 |
| start.psd | 116 × 262 | Create · Options |
| face.psd | 516 × 258 | × · ○ · □ · △ |
| sticks.psd | 440 × 440 | 왼쪽 스틱 · 오른쪽 스틱 |
| dpad.psd | 520 × 260 | 위 · 아래 · 왼쪽 · 오른쪽 |
| ps.psd | 131 × 216 | 단일 이미지 |
| base.psd | 1800 × 1460 | 단일 이미지 |

## 색상 바꾸기

1. 바꾸려는 파츠의 PSD를 엽니다.
2. 해당 파츠 그룹 → `02 PRESSED - lower row`를 펼칩니다.
3. `01 COLOR FILL` 레이어의 레이어 스타일 → 색상 오버레이에서 원하는 색을 지정합니다.
4. `02 WHITE outline and symbol`은 유지하면 흰색 선과 기호가 바뀌지 않습니다.
5. `03 MASK`는 내보내기용이므로 숨긴 채 둡니다.

기본 상태는 위쪽 줄, 눌림 상태는 아래쪽 줄입니다. **둘 다 PNG에 들어가야 하므로 NORMAL과 PRESSED 그룹을 모두 켠 상태로 내보냅니다.**
전체 패드 PSD에서 상태를 하나씩 켜던 이전 방식과 달리, 이 파일들은 실행용 스프라이트 이미지 자체를 편집하는 파일입니다.

## PNG로 교체하기

1. 투명 배경을 유지하고 PNG로 내보냅니다.
2. **크기 100% / 캔버스 크기 유지 / 투명 여백 유지**로 내보냅니다. 내용만 잘라내거나 자동 Trim 하지 마세요.
3. 원본과 같은 파일명으로 저장합니다. 예: dpad.psd → dpad.png.
4. 로컬 사용: `local/dpad.png`를 교체하고 OBS 소스를 새로고침합니다.
5. GitHub 사용: 저장소 main 루트의 `dpad.png`를 교체하고 OBS 캐시를 새로고침합니다.

캔버스 크기·각 파츠 위치를 유지한 채 색상이나 테두리를 편집하면 CSS 좌표를 바꿀 필요가 없습니다.
테두리를 두껍게 하거나 모양을 크게 바꿀 때는 기존 칸을 넘지 않게 하세요. 칸 크기까지 바꾸면 CSS도 수정해야 합니다.

본체에 기본 L2/R2 모습이 포함되어 있습니다. L2/R2 기본 외형을 바꾸면 `base.psd`의 neutral base와 `triggers.psd`의 NORMAL도 함께 수정해야 합니다.
스틱 고정 링은 `base.psd`, 움직이는 캡과 클릭 상태는 `sticks.psd`에 있습니다.
PS는 버튼 면 대신 로고 자체의 색상이 바뀝니다.

모든 편집 레이어는 래스터입니다. 검증 결과는 verification.json에 기록했습니다. PSD 렌더러의 알파 반올림 차이는 색상 채널당 최대 1/255까지 허용했습니다.
